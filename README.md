# Orbit — лаунчер для Mi Box S

Свой домашний экран для Android TV (Mi Box S 1st gen, Android 9).
Kotlin + Jetpack Compose for TV, без Google-сервисов и рекомендаций.

## Что умеет (v0.1)

- **Главный экран**: часы/дата, ряд «Избранное» (баннеры 16:9), сетка всех приложений (5/6/7 колонок).
- **Долгое нажатие OK** на приложении: открыть, в избранное / убрать, переместить, скрыть, «О приложении», удалить.
- **Перестановка избранного**: «Переместить» → ◀ ▶ двигают карточку, OK или «Назад» — готово.
- **Установка APK** (кнопка «Установить APK»):
  - **Витрина**: список приложений из JSON. Встроены SmartTube stable/beta. Можно указать свой JSON-URL.
  - **USB / память**: браузер по флешке и внутренней памяти, плюс режим «Все APK» (поиск по носителю).
  - **По ссылке**: любая прямая или короткая ссылка (редиректы обрабатываются), список недавних.
  - Перед установкой показывает пакет, версию и то, что сейчас установлено. Ставит через `PackageInstaller` session.
- **Настройки**: колонки, источник витрины, разрешение «неизвестные источники», системные настройки, скрытые приложения.
- Кнопка Home на пульте всегда возвращает на главный экран. «Назад» на главном ничего не закрывает.
- При первом запуске SmartTube, YouTube, Netflix, VLC, Kodi и т.п. (если установлены) сами попадают в избранное.

## 1. Сборка APK

### Вариант А — GitHub Actions (без Android Studio)

1. Создай **приватный** репозиторий и запушь проект:
   ```bash
   git init && git add . && git commit -m "Orbit v0.1"
   git branch -M main
   git remote add origin git@github.com:<you>/orbit-launcher.git
   git push -u origin main
   ```
2. **Actions → Build APK** → последний запуск → Artifacts → `orbit-launcher-apk`.
3. Для GitHub Release с прямой ссылкой на APK:
   ```bash
   git tag v0.1.0 && git push --tags
   ```
   Ссылку на `.apk` из релиза потом можно вбить прямо в Orbit («По ссылке») для самообновления.

### Вариант Б — Android Studio

Открыть папку → Build → Build APK(s). Выход: `app/build/outputs/apk/`.

### Подпись

В `keystore/orbit.jks` лежит ключ (пароль `orbitlauncher`, alias `orbit`). Им подписываются и debug, и release,
поэтому новые версии ставятся поверх старой. **Держи репозиторий приватным.**
Свой ключ: добавь в GitHub Secrets `ORBIT_KEYSTORE_B64` (`base64 -w0 my.jks`), `ORBIT_KEYSTORE_PASSWORD`,
`ORBIT_KEY_ALIAS`, `ORBIT_KEY_PASSWORD`. Смена ключа = один раз удалить старую версию.

## 2. Установка на Mi Box S

1. Включи режим разработчика: **Настройки → Настройки устройства → Об устройстве → «Сборка» 7 раз**.
2. **Для разработчиков → Отладка по USB: вкл.** Приставка и ПК должны быть в одной сети.
   IP: Настройки → Сеть → твоя Wi-Fi.
3. С ПК (или с телефона через любое ADB-приложение):
   ```bash
   adb connect 192.168.1.50:5555          # IP приставки, на ТВ подтверди «Разрешить»
   adb install -r orbit-launcher-*.apk
   ```

## 3. Сделать Orbit лаунчером по умолчанию

На Mi Box S стоковый лаунчер перехватывает Home, выбора лаунчера в настройках нет, поэтому отключаем его:

```bash
# проверить, что Orbit стоит и запускается:
adb shell am start -n dev.orbit.launcher/.MainActivity

# какие лаунчеры есть на прошивке
adb shell pm list packages | grep -iE "launcher|tvlauncher"

# отключить стоковый (Android 9 / Mi Box S)
adb shell pm disable-user --user 0 com.google.android.tvlauncher
# если на прошивке есть старый leanback-лаунчер — его тоже
adb shell pm disable-user --user 0 com.google.android.leanbacklauncher
```

Нажми Home на пульте — откроется Orbit. Если система спросит, какой лаунчер использовать, выбери Orbit → «Всегда».

**Откат** (если что-то пошло не так, например чёрный экран):
```bash
adb shell pm enable com.google.android.tvlauncher
```

> После OTA-обновления прошивки стоковый лаунчер может включиться обратно — просто повтори `disable-user`.
> Отключение `tvlauncher` не ломает YouTube, Play Store и голосовой поиск. Пропадают только рекомендации на главном экране Google.

## 4. Разрешение на установку APK

При первой установке Orbit попросит разрешение и откроет нужный экран:
**Настройки → Настройки устройства → Безопасность и ограничения → Неизвестные источники → Orbit: вкл.**

## Важно про архитектуру

У Mi Box S **32-битное** пространство (armeabi-v7a), хотя чип 64-битный. Если APK бывает в разных
сборках, бери `armeabi-v7a` или `universal`. `arm64-v8a` не встанет (ошибка «несовместим»).

## Своя витрина

Залей JSON куда угодно (Vercel, GitHub raw, свой сервер) и укажи URL в Настройках → «Источник витрины».

```json
{
  "apps": [
    {
      "name": "SmartTube",
      "package": "com.teamsmart.videomanager.tv",
      "description": "YouTube без рекламы",
      "url": "https://github.com/yuliskov/SmartTube/releases/download/latest/smarttube_stable.apk"
    }
  ]
}
```

- `package` нужен для статуса «Установлено · vX» и кнопки «Обновить». Без него запись тоже работает.
- Ссылки могут быть с редиректами (GitHub releases `latest`, `kutt.to/...`).

## Структура

```
app/src/main/java/dev/orbit/launcher/
├── MainActivity.kt          HOME-активити, навигация, кнопка Home
├── MainViewModel.kt         состояние: приложения, избранное, установка, витрина
├── OrbitApp.kt              синглтоны + слушатель установки/удаления пакетов
├── data/
│   ├── AppRepository.kt     список приложений (LEANBACK + обычные), запуск, удаление
│   ├── IconCache.kt         баннеры/иконки → ImageBitmap, цвет фона карточки
│   └── Prefs.kt             избранное, скрытые, колонки, URL витрины
├── install/
│   ├── ApkInstaller.kt      PackageInstaller session, разбор APK, тексты ошибок
│   ├── InstallResultReceiver.kt  результат установки + системное подтверждение
│   ├── Downloader.kt        загрузка с прогрессом и ручными редиректами
│   ├── Catalog.kt           витрина (JSON)
│   └── Storage.kt           носители, листинг, поиск APK
└── ui/                      Compose for TV: главный, установка, настройки, диалоги
```
